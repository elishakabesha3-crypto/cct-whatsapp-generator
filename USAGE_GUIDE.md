# CCT WhatsApp Message Generator - Usage Guide

Welcome to the Call Center Team (CCT) WhatsApp Message Generator! This tool automates message creation for your WhatsApp group, eliminating the need to type repetitive messages.

## Overview

The generator has **4 main message types**:

### 1. 🏧 ATM Report
For reporting ATM downtime and service issues.

**What you fill in:**
- Select the ATM (or add a new one)
- Select the Location
- Set the Time
- Assign to an Engineer

**What gets generated:**
A formatted message with:
- Alert indicator
- ATM name & location
- Time reported
- Assigned engineer
- Professional signature from CCT

### 2. 🖥️ IT Issue Report
For reporting IT and system issues.

**What you fill in:**
- Describe the issue (text area)
- Assign to an Engineer

**What gets generated:**
A formatted message with:
- Alert indicator
- Issue description
- Assigned engineer
- Professional signature from CCT

### 3. 📞 First Line Call Alert
For incoming first-line support calls.

**What you fill in:**
- Caller Contact (phone or email)
- Issue Type (select from dropdown)
- Assign to Engineer

**Available Issue Types:**
- Network Connectivity
- Software Issue
- Hardware Problem
- Access Issue
- Performance Problem
- System Down
- Other

**What gets generated:**
A formatted message with:
- Alert indicator
- Caller contact info
- Issue type
- Assigned engineer
- Professional signature from CCT

### 4. ✉️ Manual Message
For custom messages not covered by the other types.

**What you do:**
- Type your custom message
- The system adds professional greeting and signature

**What gets generated:**
Your message with:
- Alert indicator
- Your custom text
- Professional signature from CCT

## How to Use

### Step 1: Select Message Type
Click the button for the message type you need in the left sidebar:
- 🏧 Generate ATM Report
- 🖥️ Report I.T Issue
- 📞 First Line Call
- ✉️ Manual Message

### Step 2: Fill in Required Fields
Enter the specific information for that message type. Fields vary by message type.

### Step 3: Preview the Message
Before sending, you'll see a **Message Preview** showing exactly what will be sent to WhatsApp, including:
- The formatted layout
- Professional greeting
- All details
- Team signature

### Step 4: Generate & Send
1. Click **"Generate Message"** - this saves it to your history
2. A preview link appears automatically
3. Click **"Send to WhatsApp"** button to open WhatsApp with the message ready to send

### Step 5: Copy to Your Group
The WhatsApp link opens with the message already formatted. Simply:
- Select your CCT WhatsApp group
- Review the message
- Click Send

## Managing Dropdowns

### Adding New Options
For dropdowns like ATM, Location, and Engineers:
1. Find the "Add new..." field below the dropdown
2. Type the new entry
3. Click "Add" button
4. The new option is saved for future use

### Engineers List
The engineers list is shared across all message types, so adding an engineer once means they appear in all forms.

## Message History

All messages you generate are saved in the **Sent Messages History** section. This shows:
- Complete formatted messages
- Newest messages first
- Full message preview before sending

## Pro Tips

✅ **Save common entries** - Add frequently used ATMs, locations, and engineers early so you just select them later

✅ **Use Message Preview** - Always check the preview before sending to catch any typos

✅ **Keep it professional** - The system adds professional formatting, so just focus on the key facts

✅ **Consistent communication** - All messages use the same professional format for brand consistency

## Message Format

All messages include:

**Beginning:**
```
🔔 ALERT

[Your specific message content]
```

**Ending:**
```
---
Call Center Team (CCT)
Automated Message Generator
```

This ensures every message is professional and clearly identifies it as coming from the CCT automated system.

## Troubleshooting

**Nothing appears in the dropdown?**
- Make sure you've added entries first using the "Add new..." field

**WhatsApp link doesn't work?**
- Make sure you have WhatsApp installed or WhatsApp Web open
- The link will automatically open WhatsApp with the message ready

**Message looks wrong in preview?**
- Check that all fields are filled in correctly
- The preview updates automatically as you type

## Need Help?

If you encounter any issues, check that:
1. All required fields are filled (form will alert you otherwise)
2. You're using a supported browser with WhatsApp access
3. Your engineer/ATM/location names are correctly spelled

Happy messaging! 🚀
