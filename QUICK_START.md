# Quick Start - CCT WhatsApp Generator

## 🚀 Get Started in 2 Minutes

### 1. Open the Dashboard
Navigate to your dashboard at `/dashboard`

### 2. Choose Your Message Type
Click one of the four buttons in the left sidebar:
- **🏧 Generate ATM Report** - ATM is down
- **🖥️ Report I.T Issue** - IT/System problem
- **📞 First Line Call** - Incoming support call
- **✉️ Manual Message** - Custom message

### 3. Fill in the Details
Type in the specific information required by that message type.

### 4. See the Preview
As you fill in fields, you'll see the **Message Preview** box showing exactly what will be sent - with professional formatting already applied!

### 5. Send to WhatsApp
Click **"Send to WhatsApp"** button. WhatsApp opens with your message ready to send. Just:
1. Select your CCT group
2. Review the message
3. Click Send

Done! ✅

---

## 📋 What Each Message Type Does

### ATM Report
You fill in: ATM name, Location, Time, Engineer assigned
System generates: Professional formatted ATM downtime alert

### IT Issue Report
You fill in: Issue description, Engineer assigned
System generates: Professional formatted IT issue alert

### First Line Call
You fill in: Caller contact, Issue type, Engineer assigned
System generates: Professional formatted call alert

### Manual Message
You fill in: Your custom message
System generates: Your message + professional greeting & signature

## 💡 Pro Tips

✅ **Add commonly used entries once** - Engineers, ATMs, and locations are saved. Once you add them, just select from the dropdown next time.

✅ **Always check the preview** - The preview box shows exactly what will be sent. No surprises!

✅ **All messages are saved** - Click "Sent History" in the sidebar to see all messages you've generated.

✅ **The formatting is automatic** - You just provide the facts, the system handles the professional layout.

## 🔍 Example: How to Report an ATM Down

1. Click **🏧 Generate ATM Report**
2. Select or add your ATM name (e.g., "ATM-Lusaka-01")
3. Select or add location (e.g., "Shopping Mall Downtown")
4. Set the time the ATM went down
5. Select or add the engineer assigned (e.g., "James Banda")
6. See the preview populate automatically
7. Click **"Send to WhatsApp"**
8. WhatsApp opens - select the CCT group and send!

The message that goes out looks like:
```
🔔 ALERT

⚠️ ATM DOWN - URGENT

ATM: ATM-Lusaka-01
Location: Shopping Mall Downtown
Reported At: 14:30
Assigned Engineer: James Banda

---
Call Center Team (CCT)
Automated Message Generator
```

## ⚠️ Quick Troubleshooting

**Dropdown is empty?**
- You need to add entries first. Use the "Add new..." field below the dropdown.

**WhatsApp link doesn't open?**
- Make sure WhatsApp is installed or WhatsApp Web is open in another tab.
- The link is automatically created when you have all fields filled.

**Preview won't show?**
- Fill in all required fields - the preview updates automatically once everything is complete.
