```

Dark:       #1e40af (Dark Blue) ..... Gradients, depths
Success:    #10b981 (Emerald) ....... Send actions, success
Background: #0f0f12 (Deep Slate) .... Main background
Card:       #1a1a1f (Light Slate) ... Component backgrounds
```
