## 🛠️ Technical Details

**What's Running**:
- Next.js React application
- TypeScript for type safety
- Tailwind CSS for styling
- Browser localStorage for data
- WhatsApp Web integration via wa.me links

**What You Need**:
- Modern web browser
- WhatsApp installed OR WhatsApp Web open
- Internet connection

**No Server Needed**:
- All processing happens in your browser
- Data stored locally on your device
- Can work offline for message generation

## 🔄 The Message Flow

```
User Input
    ↓
Form Fields
    ↓
Message Formatter (adds greeting & signature)
    ↓
Preview Display (shows formatted message)
    ↓
localStorage Save (when "Generate" clicked)
    ↓
WhatsApp Link (when "Send" clicked)
    ↓
WhatsApp Opens (message pre-filled)
    ↓
Select Group & Send
```
